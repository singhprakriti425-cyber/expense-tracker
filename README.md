# Expense Tracker 💰

A simple and interactive web-based Expense Tracker built using HTML, CSS, and JavaScript.

## ✨ Features

* Add and manage expenses
* Calculate total expenses
* View expense history
* Monthly expense tracking
* Interactive expense chart
* Saving tips
* Dark/Light mode
* Simple and user-friendly interface

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open `expense.html` in your browser.
3. Start adding your expenses.
